# PHONECASE 📱

A modern phone-case design studio built with **Next.js, TypeScript, Tailwind CSS, Konva, and Firebase**.

Design your own case by choosing your phone, uploading images, adding backgrounds, text and shapes, then preview and order it.

## ✨ Features

* 📱 Phone & case selection
* 🎨 Drag, resize, rotate & crop designs
* 🖼️ Custom image uploads
* 🌌 Wallpaper library
* ✍️ Text & shapes
* 🧩 Templates & layers
* 💾 Automatic draft saving
* 🖨️ Preview & print export
* 📦 Firebase-powered orders
* 💬 WhatsApp order confirmation
* 🔐 Admin dashboard

## 🛠️ Tech Stack

**Next.js · React · TypeScript · Tailwind CSS · Konva · Firebase · Zustand · Framer Motion**

## 🚀 Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
